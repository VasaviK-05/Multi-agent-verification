## Dependency robustness heatmap

Generated by `evaluation/experiments/experiment3/synthetic_dependency_heatmap.py`. The existing `synthetic/results.json` was not modified.

Assumptions, scored by `DependencyRegistry.groups` and `enumerate_attacks`:

- Independent: semantic, evidence, rule, and confidence are separate failure groups.
- Correlated: semantic and evidence share one group. Rule and confidence are separate.
- Fully correlated: all four verifiers share one group.

Attacks in the figure are clean, forced support, forced rejection, and confidence inflation. The engine also enumerates suppression because the attack specification marks it unavailable. Those suppression columns are not the plotted cells. When an attack kind has several groups, the cell is the worst group loss for that kind. Every group loss is in the JSON.

Scoring uses `fit_policy`, `restricted_matrix`, and `solve_minimax`. The plotted validation loss is `Metrics.mean_loss`: decision loss plus 0.1 times estimated attempt cost. Loss weights are the synthetic fixture weights, false accept 1, false reject 1, uncertain 0.2. History reports are abstentions, because a mixed directional history did not satisfy the history-snapshot binding. Development reports are directional and correct. One synthetic example is scored. The manifest schema requires a `final_test` partition; that partition is synthetic and is not scored. No Final Test label file was opened.

`prepare_comparison` was not used. Its readiness gate requires a resource-bound evidence validation when an evidence adapter is present. This fixture does not invent that observation.

On this fixture the three aggregation methods produce the same expected loss. The dependency assumption does not. Forced-rejection loss is 0.3 when each verifier is separate, about 0.333 when semantic and evidence share a group, and 1.1 when all four share a group. Clean loss is 0.2 for the first two assumptions and 0.1 for the fully correlated group. These numbers are fixture scores, not Development estimates and not measured dependence.
