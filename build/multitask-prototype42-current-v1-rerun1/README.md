# Current setup task-policy bundle v1

Fresh empirically fitted artifacts for the frozen current setup. Arithmetic is a 0.50 development clean-coverage target; factual is 0.25 and remains experimental. The original prototype artifacts remain unchanged historical records. This package does not activate production or include raw study reports, final-test payloads, model weights, corpus/index bytes, machine paths or credentials.

Validate with `python -m app.game.offline.prototype validate --bundle build/multitask-prototype42-current-v1`. Runtime requires the exact resource manifest in each task's resources.json, an explicitly verified relocation binding where the historical index is relocated, the task router and live resource observer. Only question IDs listed in manifest.json are in scope. Both tasks require a nonblank reference. Uncertainty, contributor, achieved-coverage and failure guards are retained.
