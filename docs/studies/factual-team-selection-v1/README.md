- Resource penalty **0.00001 loss/ms** (0.1 loss per 10,000 estimated ms), false-accept/false-reject losses **1/1**, uncertainty loss **0.2**. - Both `reputation_weighted/log_odds_v1` and `dependency_group/groups_v1`, all feasible strategies including probability zero. Optimizer certificate tolerance 1e-8, scientific repeat tolerance 1e-12 absolute, proposed sampling seed 20261028. No positive probability or randomization requirement.
- Existing `report_corruption_v1` with unavailable suppression. Actual common embedding bytes link Semantic/Evidence; actual common NLI bytes link Evidence/Confidence. Their observed digests are retained in the proposed dependency records. All four remain conservatively unresolved under existing `shared_unknown`, giving one connected failure group.
