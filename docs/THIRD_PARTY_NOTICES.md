# Included data and excluded runtime resources

GeoNames countryInfo is attributed to [GeoNames](https://www.geonames.org/).
Its [export terms](https://www.geonames.org/export/) describe Creative Commons
Attribution licensing and require credit. The archived snapshot and its SHA-256
remain in `artifacts/compound-study-36-v1/portable-inputs/`; a newly downloaded
countryInfo file can differ. Population labels and the derived retrieval corpus
retain GeoNames attribution and original source URLs.

The countries snapshot is attributed to [mledoze/countries](https://github.com/mledoze/countries),
revision `6031f5df137c41c76d180c55a0782185ae3ed05b`. Its Open Database License
text is retained at `artifacts/compound-study-36-v1/portable-inputs/LICENSE`.
The included database snapshot, numeric extracts and derived retrieval corpus
retain this notice and the source/revision/hash manifests. The database license
does not purport to relicense the prototype's implementation code.

Model weights/tokenizers, FAISS index binaries, the Ollama installation/model,
Python environment, DB/user data and unrelated original-execution source custody
archives are excluded from this publication. Exact model revisions and individual
file/directory hashes, corpus/index receipts, service/model metadata and dependency
versions are provided as verification evidence. Obtain the exact approved resources
from their upstream publishers or experiment custodian, respect their corresponding
licenses, and verify hashes. No mutable alias, download or rebuild is automatically
compatible. This is not a self-contained executable deployment.

Personal local path prefixes in audit metadata are excluded from staged originals.
Separate derived public views and their original/public hashes are listed in
`artifacts/publication-v1/owned-files.json`. Those views cannot replace canonical
whole-freeze identity inputs. Original policy/context/matrix bytes needed for
portable certificate validation remain unchanged. Canonical private-path source
audits are available from the experiment custodian by original relative filename
and SHA-256; they are not required merely to load policies or replay retained reports.
