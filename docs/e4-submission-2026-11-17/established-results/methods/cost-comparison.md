# Estimated versus actual cost

[Historical observations](../data/calibration/historical-observations.csv) contain 480 included Development external verify-call measurements, 120 per verifier. [Raw measurements](../data/calibration/measurements.json) retain all 488 calls, including eight warmups. [Estimates](../data/calibration/estimates.json) preserve include_warmups=false and mean_attempt_wall_time_ms_v1. Setup/verifier fingerprints and units match the bound inputs. Historical fitted means equal the corresponding observed means by construction: this is in-sample calibration, not an independent prediction experiment.

[Current Rule observation](../data/calibration/current-rule-observation.csv) separately compares the deployed frozen estimate 9.678209995036013 ms with the exact external original native verify-call duration 1.1290 ms. Both refer to external verify wall time and exclude constructor/resource observation and post-call validation/recording. The [frozen cost source](../data/configuration/cost-estimate-source.json), [policy binding](../data/configuration/policy-binding.json), actual response and resource-transfer proof provide identity traceability. This is one current observation against a historical mean, with instrumentation effects and a reviewed source/resource transfer; it does not recalibrate the policy or establish a general error rate.

The datasets retain every historical observation, each historical fitted mean, and the separately identified current Rule observation and its frozen estimate. Current and historical configuration strata are not pooled. These costs are wall milliseconds, not money, CPU utilization or HTTP request time.
